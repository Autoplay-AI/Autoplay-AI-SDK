## What drives the price

You pay based on how many end users receive proactive, personalized assistance — not for tools you already own.

| Driver | What it means | How it's billed |
| --- | --- | --- |
| Users receiving personalized assistance | Each user Autoplay is actively guiding, learning from, and improving suggestions for | **The unit** — this is what scales with your plan |
| User session lifecycle management | Session continuity across visits so your agent always knows where a user left off | **Included** in every plan |
| Signal feedback loop | Tracks how each user responds to proactive suggestions; continuously evaluates and self-corrects | **Included** in every plan |
| Your existing tools | Session replay, chatbot, visual guidance — already yours; Autoplay orchestrates them | **Not metered** — you keep your stack |
