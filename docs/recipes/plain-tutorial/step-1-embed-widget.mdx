**Plain** surfaces live user context the moment a support thread opens — no asking, no digging. This step creates the server-side credential [Step 2](/recipes/plain-tutorial/step-2-enrich-threads) uses to attach recent in-app activity to every thread automatically.

<Info>
  **Before you begin.** You'll need a Plain workspace with a Live Chat app created and the `liveChatApp_...` App ID copied. Follow [Plain's setup guide](https://plain.com/docs) if you haven't done that yet.
</Info>

## 🤖 1. Create a Machine User

A Machine User is a service account that authenticates server-side API calls to Plain. Step 2 reads thread data and writes notes on behalf of this user.

1. Go to **Settings → Machine users**
2. Click **New machine user**
3. Give it a name (e.g. `Autoplay Integration`)
4. Under **Roles**, assign at least **Member** (required to read threads and create notes)
5. Click **Create**, then **Create API key** — copy the key immediately, it won't be shown again

Save the key to your environment config now:

```env
PLAIN_API_KEY=your_machine_user_api_key_here
```

<Warning>
  This key is a server-side secret. Never expose it in client-side code or commit it to source control.
</Warning>
