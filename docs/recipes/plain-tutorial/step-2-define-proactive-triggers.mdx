<Note>
  **Coming soon.** Proactive triggers for Plain — reaching out automatically based on what a user is doing in your product (a stuck flow, a repeated error, a high-intent moment) — are on the way.
</Note>

Once **[Step 1 — Connect real-time events](/recipes/plain-tutorial/step-1-connect-real-time-events)** is set up, Plain can already *attach* a user's recent activity to every support thread automatically. Proactive triggers add the other direction: reaching out automatically, without waiting for the user to open a thread.

Want early access or have a use case in mind? Join our [Discord](https://discord.gg/jCbR2tQA5) and let us know.
