---
title: Improve CSAT
sidebarTitle: "⭐ Improve CSAT"
description: Deliver relevant, consistent support informed by what users have actually done in your product.
---

When every interaction is informed by what a user has actually done in your product, responses feel relevant instead of generic. Users feel understood. That consistency — across every session, every touchpoint — is what turns satisfaction scores into lasting loyalty.

<Tabs sync={false}>
  <Tab title="Session 1">
    ```text
    User: How do I connect an integration?

    Bot: Sure! Head to Settings → Integrations and click "Add new". You'll
    need your API key handy.

    Which integration are you looking to connect?

    User: I got it, thanks!
    ```
  </Tab>
  <Tab title="Session 2 — next day">
    ```text
    Remembered from last session:
    User struggled with API key setup. Completed it after walkthrough.
    Has not yet connected a second integration.

    User: Hey, I want to add another integration now

    Bot: Welcome back! Since you already set up your first one, this should
    be quick — same flow in Settings → Integrations.

    You'll have your API key from last time. Which integration are you adding?

    (Same user, next session — the agent remembers. No re-explaining from scratch.)
    ```
  </Tab>
