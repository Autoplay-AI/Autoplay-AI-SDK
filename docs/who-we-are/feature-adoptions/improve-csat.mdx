## Outcome

Higher satisfaction scores because support feels instant, accurate, and personal — not generic.

## How Autoplay helps

- **LLM-ready context** — assemble live actions, chat history, and KB snippets in one pipeline. See [Chatbot context assembly](/sdk/chatbot-context-assembly).
- **Reactive assistance** — when users do open chat, the agent already has their session trail. See [Agent session states](/sdk/agent-states).
- **Summarisation** — keep long sessions readable for models and agents. See [Summarizer](/sdk/summarizer).

## Get started

Build the full stack with [compose_chat_pipeline](/sdk/compose-chat-pipeline) or follow the [proactive copilot recipe](/sdk/proactive-copilot).
