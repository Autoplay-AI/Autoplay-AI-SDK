Surface the right features to the right users based on their history and in-product behavior. Instead of interrupting with a push notification or a forced modal, the upgrade conversation happens inside the chat — contextual, timely, and friction-free. Less forced, more converting.

<Tabs sync={false}>
  <Tab title="Answer first">
    ```text
    Context: User has manually exported this report 4× this week

    User: How do I filter this report by date range?

    Bot: Click the date picker at the top right of the report — you can set
    a custom range or pick from presets like last 7 days, last 30 days, etc.

    User: Perfect, got it!
    ```
  </Tab>
  <Tab title="Then upsell naturally">
    ```text
    Context: User has manually exported this report 4× this week

    User: How do I filter this report by date range?

    Bot: Click the date picker at the top right of the report — you can set
    a custom range or pick from presets like last 7 days, last 30 days, etc.

    User: Perfect, got it!

    Bot: Also — I noticed you've been exporting this report manually a few
    times this week. Just so you know, on the Growth plan you can schedule
    it to run automatically and drop straight into your inbox. Might save
    you a lot of back and forth!

    (Question answered first. Upsell feels earned. No interruption.)
    ```
  </Tab>
</Tabs>
